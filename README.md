# mijn-site

Persoonlijke site van Thomas, gehost met GitHub Pages.

## Structuur

- `index.html`, `over.html`, `links.html` – de pagina's
- `css/style.css` – stijl, paginatransities en animaties
- `js/main.js` – scroll-reveal, muisgloed en magnetische knoppen

Geen buildstap nodig: GitHub Pages serveert de bestanden direct vanaf `main`.
